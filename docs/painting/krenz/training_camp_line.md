# PS 设置

- 打开 ctrl+o
- 画笔 B
  - 工具栏 | 设置
    - 勾选：画笔名称、画笔描边、画笔笔尖
    - 模式：正常；不透明度：100%；流量：100%；平滑：0%
  - [ 、] 调节笔刷大小
  - 推荐笔刷
    - 3 石墨铅笔：打框，草稿
    - 5 尖角5像素：练线、线稿
- 橡皮 E
- 套索 L
  - 叠图检查：选中检查图层，圈出来，ctrl+拖动鼠标
- 取消选区 ctrl+d
- 自由变换 ctrl+t
- 调节画布大小 alt+鼠标滚轮
- 切到移动画布功能 H
- 图层：背景、打框、草稿、线稿
- 撤销 ctrl+z
- 恢复 ctrl+shift+z
- 横竖直线 长按 shift 画线
- 任意两点直线 点点A，按住shift 点B
- 导出，快速导出为PNG
- 复制图层 ctrl+j
