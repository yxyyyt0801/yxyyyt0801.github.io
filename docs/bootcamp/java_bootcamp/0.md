# JVM

## 基础知识

- 虚拟机（基于栈的计算机器）+运行时+GC内存管理

- 跨平台

- 类加载器（加载、链接、初始化、使用、卸载）

- JVM 内存模型（栈、堆、非堆、JVM自身）

  - -Xmx（防止OOM，不超过总内存的70%）

- 启动参数

  - -server 标准参数

  - -Dfile.encoding=UTF-8 设置系统属性（环境变量）
  - -Xmx8g 非标准参数
  - -XX:+UseG1GC 非稳定参数
